# OJT Log downloads

Attendance and daily journaling for Android and Windows, by KM STUDIO.

[Download the latest installers](https://github.com/leukem15-ux/OJT-Log-Releases/releases/latest)

Downloads are free and do not require a GitHub account. This repository contains distribution information, not the application project source.

## Install

- Windows 10/11, 64-bit: download the Windows ZIP, extract the entire folder, exit OJT Log from the tray, then run `OJT Log Setup.exe`.
- Android: install the APK over your existing app. Do not uninstall first if you want to retain local data. Android asks for installation approval.
- Compare your downloaded files with `SHA256SUMS.txt`.

Back up important records before updating. Windows and Android versions can differ. Automatic Source code archives are not app installers. Never upload journal backups, tokens, passwords, or signing keys here.

## App update checks

Windows 1.53.18 and Android 1.53.17 introduce the update checker. Install this first version manually. It checks GitHub once daily while open; use Settings > App updates > Check for updates for an immediate check. Newer platform installers trigger a dismissible notice. Downloads open your browser; installation is not silent. The current version should say it is up to date until another newer release is published. GitHub rate limits and internet availability apply.
