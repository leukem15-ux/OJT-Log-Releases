# OJT Log downloads

Attendance and daily journaling for Android and Windows, by KM STUDIO.

[Download the latest installers](https://github.com/leukem15-ux/OJT-Log-Releases/releases/latest)

Downloads are free and do not require a GitHub account. This public repository contains distribution information, not the application project source.

## Choose your file

- **Windows 10/11, 64-bit:** choose the Windows `.zip` asset. Extract the entire ZIP, choose Exit OJT Log from the existing app’s tray menu, and run `OJT Log Setup.exe`.
- **Android:** choose the `.apk` asset. Install over your existing app as an update; avoid uninstalling first if you want to retain local data. Android will ask you to approve installation.
- **Checksums:** compare your downloaded file with `SHA256SUMS.txt` in the same release.

Windows and Android version numbers can differ; follow the release title and file names. GitHub’s automatically generated Source code archives are not app installers.

Back up important records before updating. Never upload journal backups, access tokens, passwords, or signing keys to this repository or public issues.
